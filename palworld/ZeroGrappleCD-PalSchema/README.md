# ZeroGrappleCD (PalSchema) — server only

Sets `CoolDownTime` and `NearCoolTimeRate` to `0` on all four grappling guns.

## Install (dedicated / Palsitter)

```
.../ue4ss/Mods/PalSchema/mods/ZeroGrappleCD/
  blueprints/Grappling Guns.jsonc
```

Restart the server. **No client Lua required.**

## Tiers

| Gun | Blueprint |
|-----|-----------|
| Grappling Gun | BP_GrapplingGun_C |
| Mega | BP_GrapplingGun_2_C |
| Giga | BP_GrapplingGun_3_C |
| Hyper | BP_GrapplingGun_4_C |
